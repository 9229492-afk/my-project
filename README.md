# my_shop_bot

Telegram-бот для магазина: покупатель смотрит каталог, оформляет заказ в чате,
готовый заказ приходит владельцу магазина в личные сообщения.

## Что умеет

| Команда | Что делает |
|---|---|
| `/start` | Приветствие и список команд |
| `/help` | Справка |
| `/catalog` | Каталог товаров кнопками, карточка товара |
| `/oferta` | Присылает публичную оферту (PDF) |
| `/vozvrat` | Присылает правила возврата и обмена (PDF) |
| `/id` | Показывает твой Telegram ID (нужен для `ADMIN_ID`) |
| `/cancel` | Прерывает оформление заказа на любом шаге |

Кнопка «🛒 Купить» в карточке товара запускает диалог: имя → телефон → адрес →
подтверждение. После подтверждения заказ уходит владельцу в личку.

## Как запустить

### Шаг 0. Что нужно на компьютере

Python 3.11 или новее и git. Проверить:

```bash
python3 --version
git --version
```

Если Python нет — скачай с [python.org](https://www.python.org/downloads/).
На Windows при установке **обязательно поставь галочку «Add Python to PATH»**,
иначе команды не найдутся.

### Шаг 1. Получить токен бота

В Telegram найди **@BotFather** → отправь `/newbot` → придумай имя и адрес бота
(адрес должен заканчиваться на `bot`). В ответ придёт строка вида
`123456789:AAH...` — это токен.

> ⚠️ Токен — это пароль от бота. Никому не показывай и не коммить в git.
> Если он всё же попал в репозиторий — сразу отзови его через @BotFather
> и выпусти новый: из истории git строку так просто не убрать.

### Шаг 2. Забрать код

```bash
git clone https://github.com/9229492-afk/my-project.git
cd my-project
```

### Шаг 3. Виртуальное окружение

Отдельная папка с библиотеками только для этого проекта — чтобы установленное
здесь не мешало другим проектам.

**macOS / Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

**Windows (PowerShell):**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

Получилось, если в начале строки терминала появилось `(.venv)`.
Это нужно повторять каждый раз, когда открываешь новый терминал.

### Шаг 4. Установить библиотеки

```bash
pip install -r requirements-dev.txt
```

### Шаг 5. Создать файл .env

```bash
cp .env.example .env      # Windows: copy .env.example .env
```

Открой `.env` в редакторе и вставь токен из шага 1:

```
BOT_TOKEN=123456789:AAH...твой токен...
ADMIN_ID=
```

`ADMIN_ID` пока оставь пустым — заполним на шаге 7.

### Шаг 6. Запустить

```bash
python -m bot
```

В терминале появится `Бот запущен` и предупреждение, что `ADMIN_ID` не заполнен —
так и должно быть. Бот работает, пока открыт терминал. Остановить — `Ctrl+C`.

### Шаг 7. Узнать свой ID и вписать его

Не закрывая терминал, найди своего бота в Telegram и отправь:

- `/start` — **обязательно.** Telegram запрещает ботам писать первыми тому, кто
  им не писал. Без этого заказы до тебя не дойдут.
- `/id` — бот пришлёт твой числовой ID.

Впиши это число в `.env`:

```
ADMIN_ID=123456789
```

Нужно именно число, а не `@username`.

### Шаг 8. Перезапустить и проверить

`Ctrl+C`, затем снова `python -m bot`. Предупреждения про `ADMIN_ID` больше нет.

Теперь в Telegram: `/catalog` → выбери товар → «🛒 Купить» → пройди диалог.
После подтверждения заказ придёт тебе в личку от твоего же бота.

## Запуск без своего компьютера (с телефона)

Боту нужен компьютер, который постоянно включён. Телефон на эту роль не годится —
экран гаснет, приложение выгружается, бот замолкает. Но и покупать ничего не нужно:
есть два способа, и оба настраиваются из браузера телефона.

### Быстро проверить — GitHub Codespaces

Codespaces — это Linux с терминалом прямо в браузере. Работает, пока открыта вкладка:
для проверки годится, для постоянной работы нет.

**С телефона набирать в терминале не нужно.** Мобильный терминал VS Code плохо
дружит с экранной клавиатурой: вставка из буфера в него не проходит, а сама
клавиатура закрывает пол-экрана. Поэтому бот запускается сам — настройки берутся
из секретов Codespaces.

1. **Задай секреты.** На github.com: **Settings → Codespaces → New secret**.
   Два секрета, для обоих **Repository access → my-project**:

   | Name | Value |
   |---|---|
   | `BOT_TOKEN` | токен от @BotFather |
   | `ADMIN_ID` | твой Telegram ID |

   Это обычная веб-форма, с клавиатурой там проблем нет.

2. **Создай codespace.** Репозиторий → **Code** → вкладка **Codespaces** →
   **Create codespace on main**. Первый запуск занимает пару минут.

3. **Готово.** При открытии выполнится `.devcontainer/start-bot.sh`: он увидит
   `BOT_TOKEN` и запустит бота. В терминале появится `Бот запущен`.

   Если секреты не заданы, скрипт не падает молча, а печатает инструкцию,
   что сделать.

4. Переключись в Telegram и напиши боту `/start`. Он ответит.

Секреты подхватываются **только при создании** codespace. Если задал их позже —
удали codespace и создай заново.

Закрыв вкладку, останови codespace (**Code → Codespaces → Stop**), иначе он
продолжит расходовать бесплатные часы.

Своим `.env` этот путь не пользуется вовсе: `config.py` одинаково читает и файл,
и переменные окружения.

### Чтобы работал всегда — хостинг

Сервисы вроде Railway, Render или Amvera сами забирают код из GitHub и держат бота
запущенным. В репозитории уже лежит всё, что им нужно: `Dockerfile` и `Procfile`.

Порядок одинаковый почти везде:

1. Зарегистрироваться и подключить свой аккаунт GitHub.
2. Создать проект из этого репозитория. Тип сервиса — **worker** (фоновая задача),
   а не web: бот не отвечает на HTTP-запросы, он сам ходит в Telegram.
3. В настройках проекта добавить переменные окружения `BOT_TOKEN` и `ADMIN_ID`.
   **Файл `.env` на хостинг не загружается** — он и не должен, для этого и нужны
   переменные окружения.
4. Запустить деплой.

Тарифы и бесплатные лимиты у сервисов разные и меняются — смотри на сайте выбранного.

Следи, чтобы бот не оказался запущен в двух местах сразу (например, на хостинге и в
codespace): Telegram отдаёт сообщения только одному, второй упадёт с
`TerminatedByOtherGetUpdates`.

## Если что-то пошло не так

| Что видишь | В чём дело |
|---|---|
| `Не найден BOT_TOKEN` | Файл `.env` не создан или лежит не в той папке |
| `command not found: python3` | На Windows команда называется `python` |
| `TerminatedByOtherGetUpdates` | Бот уже запущен в другом окне — закрой лишнее |
| `Unauthorized` | Токен скопирован с ошибкой, проверь у @BotFather |
| `ADMIN_ID должен быть числом` | Вписан `@username` вместо числового ID |
| Заказ не пришёл | Ты не отправил боту `/start` (шаг 7) |

## Разработка

```bash
pytest                        # все тесты
pytest tests/test_orders.py   # один файл
ruff check .                  # линтер
ruff format .                 # форматирование
```

Тесты не требуют токена и интернета: логика каталога и заказа лежит в
`bot/catalog.py` и `bot/orders.py` отдельно от кода Telegram.
